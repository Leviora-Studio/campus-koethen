# Technical and security review: changes since 2026-10-05

Review date: 2026-11-16. Repository: Campus Köthen.

## Scope and method

Reviewed all **108 tracked files changed across 14 commits** after 2026-10-05,
from `2fa1e526c93448115fc1e86bcd759f3948ad7873` (1.2.4) through
`f4a1b49a113b5dffaa1e97457779a576a3a19388` (1.2.6), together with the local
corrections described below. There were no existing uncommitted changes at the
start of this review.

The review covered the backend/CMS/calendar changes, the app's source selection,
merging, saved events and notifications, image preview, mail keyboard and todo
changes, dependency patches/lockfile, Dockerfiles, API contract, deployment
examples and documentation. It combined source review, reproduced regressions,
automated tests, real PostgreSQL and Strapi checks, dependency audits, secret
scanning and container builds/scans.

Severity below describes the impact in this project, not a vendor CVSS rating.
All listed corrections are included in release **1.2.7**; no production service
or production data was changed during this review.

## Limits

This is a source and test-based review of the specified change set, not a claim
that the complete system is free of unknown defects. It does not include a
production penetration test, a production configuration/access audit, physical
Android/iOS device testing or legal verification of the recorded privacy text.
No production database was used. Local temporary test databases are removed
after verification. Release publication does not deploy the application or backend.
